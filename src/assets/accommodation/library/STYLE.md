# Amico Accommodation Asset Library — Style Guide

Reference: soft modern illustration design system (isometric buildings, top-down floor plans).

## Perspective
- **Buildings:** 3/4 isometric exterior
- **Floors, units, rooms, beds, facilities:** top-down plan view

## Status palette
| Status | Color | Hex |
|--------|-------|-----|
| Available | Green | `#22C55E` |
| Occupied | Red | `#EF4444` |
| Reserved | Amber | `#F59E0B` |
| Maintenance | Grey | `#9CA3AF` |
| Selected | Teal | `#14B8A6` |
| Disabled | Muted grey | `#D1D5DB` |
| Mixed / Partial | Multi-color tint | green + red accents |

## Rules
- Transparent background (PNG)
- No text labels — data overlaid in app
- Empty slots for dynamic content
- Consistent soft shadow, thin grey outlines, cream/beige surfaces
